# Ozon GS Helper

Chrome-расширение для автоматической вставки GS-разделителей (`\u001d`) в коды маркировки «Честный знак» на странице Ozon Seller FBS postings.

## Назначение

При работе с отправлениями FBS на [seller.ozon.ru](https://seller.ozon.ru) коды маркировки часто копируются в «линейном» виде — без GS1-разделителей. Сканеры и система Ozon ожидают символ Group Separator (ASCII 29, `\u001d`) перед идентификаторами приложений `91` и `92`.

Расширение автоматически добавляет разделители при:
- вставке через Ctrl+V;
- вводе сканером QR/DataMatrix (посимвольный ввод + Enter);
- любом изменении значения в поле «Код маркировки».

## Формат кодов

Структура кода маркировки:

| Участок | Описание |
|---------|----------|
| `01` + 14 цифр | GTIN |
| `21` + серийный номер | переменная длина |
| `\u001d` | GS-разделитель перед `91` |
| `91` + 4 символа | ключ проверки |
| `\u001d` | GS-разделитель перед `92` |
| `92` + остаток | криптографический хвост |

Алгоритм соответствует [инструкции Ozon](https://seller-edu.ozon.ru/libra/fbs/ozon-logistika/markirovka): находим идентификаторы `91` и `92` в коде и вставляем `\u001d` перед каждым.

Пример: при вставке строки

```
0104630301673229215Y%l?Y91EE1292xjU+A8qhtFrM7jaZby0146+W2Fn4Vma/TuCEBEsQQL4=
```

в поле попадёт та же строка с двумя **невидимыми** GS-символами перед `91` и перед `92`. Визуально код выглядит так же, но длина строки увеличивается на 2 символа.

## Установка

1. Откройте `chrome://extensions` в Google Chrome.
2. Включите **Режим разработчика** (переключатель в правом верхнем углу).
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `extension/` из этого репозитория.

## Использование

1. Откройте страницу FBS postings, например:
   `https://seller.ozon.ru/app/postings/fbs?warehouseId=...&tab=awaiting_deliver`
2. Убедитесь, что в popup расширения включено **Автоформатирование включено**.
3. Отсканируйте код сканером в поле «Код маркировки».
4. Сразу после сканирования:
   - нажмите **«Форматировать поле»** в popup расширения, или
   - нажмите **Alt+Shift+M**.

Автоформатирование при сканировании тоже включено, но если Ozon не принимает код — используйте кнопку или горячую клавишу.

Чтобы временно отключить автоформатирование, снимите галочку в popup расширения.

После обновления расширения нажмите кнопку обновления на `chrome://extensions` и перезагрузите вкладку Ozon Seller.

## Автоматическая проверка

Запустите тесты логики форматирования:

```bash
node extension/utils.test.js
```

Тесты проверяют 7 примеров кодов из реальных данных, а также edge cases: уже отформатированный код, произвольный текст, короткая строка, неверная структура.

## Ручная проверка в Chrome

1. Загрузите расширение unpacked (см. раздел «Установка»).
2. Откройте страницу FBS postings на seller.ozon.ru.
3. Вставьте один код без разделителей в любое текстовое поле.
4. Откройте DevTools, выберите поле и выполните в консоли:
   ```javascript
   const v = $0.value;
   const i91 = v.indexOf('91', 18);
   const i92 = v.indexOf('92', i91 + 2);
   v.charCodeAt(i91 - 1)  // должно быть 29 (GS перед 91)
   v.charCodeAt(i92 - 1)  // должно быть 29 (GS перед 92)
   v.length               // на 2 символа больше исходного кода
   ```
5. Отключите автоформатирование в popup → вставка должна проходить без изменений.
6. Включите снова → автоформатирование восстанавливается.
7. Вставьте обычный текст (не код маркировки) → без изменений.
